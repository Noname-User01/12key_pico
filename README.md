# 12key_pico


※これを作成するには半田ごてが必要です
使用言語:CircuitPython
編集環境:Me

12個のメカニカルスイッチを用いてキーマトリクス回路（keyboard matrix）を作成した。


ダイオードマトリクス（diode matrix）方式の為、ダイオードは使用していないシンプルな自作キーボードである。


```構成図
          C0        C1        C2        C3
        --------------------------------------
R0  ──>|─[SW00]  ─>|─[SW01]  ─>|─[SW02]  ─>|─[SW03]

R1  ──>|─[SW10]  ─>|─[SW11]  ─>|─[SW12]  ─>|─[SW13]

R2  ──>|─[SW20]  ─>|─[SW21]  ─>|─[SW22]  ─>|─[SW23]
```
それぞれのキースイッチはGNDが共通化しています

フレームはblenderで作成し造形は#D printerを使用して作成した。
